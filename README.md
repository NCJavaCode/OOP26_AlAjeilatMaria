# OOP22_Init

## Практикум. Реалізація принципу інкапсуляції
### Що було зроблено

У ході практичної роботи:
- створено клас `Student`;
- додано поля для зберігання імені, віку та спеціальності студента;
- реалізовано принцип інкапсуляції;
- обмежено прямий зовнішній доступ до даних класу;
- створено методи для отримання та зміни даних;
- додано конструктор для створення об’єкта студента;
- створено метод для виведення інформації про студента;
- реалізовано перевірку правильності зміни віку студента.

Встановлення віку дозволяється лише в межах від 0 до 100 років.
У разі введення некоректного значення виводиться повідомлення про помилку.

### Реалізація інкапсуляції
Інкапсуляцію реалізовано шляхом приховування даних класу та надання доступу до них через спеціальні методи.
Контроль зміни даних реалізовано під час встановлення віку студента. Це забезпечує захист об’єкта від введення некоректних даних.
У результаті практичної роботи створено клас `Student` та реалізовано основні вимоги принципу інкапсуляції.

## Ідея проєкту
**Система обліку студентів коледжу**
Проєкт призначений для зберігання інформації про студентів, навчальні групи та коледж.

### Мета проєкту
Створити просту систему для роботи з інформацією про студентів та навчальний процес.

## Класи проєкту

### `Student`
Описує студента, його ім’я, вік та спеціальність.

### `Group`
Описує навчальну групу та спеціальність.

### `College`
Описує коледж та місто.
